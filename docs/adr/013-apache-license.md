# ADR-013 — Apache-2.0

Status: accepted
Date: 2026-08-21

## Context and decision

The project and official adapters will be licensed under Apache License 2.0. This is a permissive open-source license that allows broad use and modification.

## Consequences

- The project is open-source and available for community contribution and adoption.
- Derivative works and adaptations are permitted under the Apache-2.0 terms.
- Commercial usage and modifications are allowed by the license terms.
